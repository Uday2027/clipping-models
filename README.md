# Clipping models

Model files downloaded by the Clipping desktop app on first launch, so its
users don't need a Hugging Face account.

## speaker-diarization-community-1

- **What:** [pyannote/speaker-diarization-community-1](https://huggingface.co/pyannote/speaker-diarization-community-1),
  a speaker diarization pipeline by [pyannoteAI](https://www.pyannote.ai/),
  used by Clipping to follow whoever is speaking when cropping clips to 9:16.
- **License:** [CC-BY-4.0](https://creativecommons.org/licenses/by/4.0/).
  Redistributed **unmodified**, with attribution. All credit to pyannoteAI.
- **Download:** see [Releases](../../releases) — `speaker-diarization-community-1.zip`
  and its SHA-256 checksum.

If you use this model outside Clipping, please get it from its
[official page](https://huggingface.co/pyannote/speaker-diarization-community-1)
